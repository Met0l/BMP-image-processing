A 24-bit bitmap with Width=1, would have 3 bytes of data per row (blue, green, red) and 1 byte of padding
Width=2 would have 6 bytes of data and 2 bytes of padding
Width=3 would have 9 bytes of data and 3 bytes of padding
Width=4 would have 12 bytes of data and no padding.

Project that handles images in the BMP format as binary files. An in-terminal program that shows particular information about the image, adds a grayscale filter, an inverted colours filter, a blur filter. For every filter added, a new image is created or the initial one can be overwritten. In addition, it can crop an image to the specified dimensions, brightens the image by a specified percentage and rotates the image by 90 or 180 degrees.
